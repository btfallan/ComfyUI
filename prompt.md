# ComfyUI

## About installation

- Using a virtual environment set up by Miniconda3 and Python 3.13.14.
- ComfyUI is installed manually from the ComfyUI Git repository in the folder `C:\temp\ComfyUI\ComfyUI`.
- ComfyUI is configured to use custom folders for `user` content, `models` and `custom_nodes` located in `C:\temp\ComfyUI\ComfyUI_Custom`.

## Hardware configuration

- Windows 11
- CPU: Intel Core Ultra 7 265K
- RAM: 128.0 GB
- GPU: NVIDIA GeForce RTX 5070 Ti
